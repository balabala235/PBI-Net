# Experiment protocol

We use the following settings for the experiments reported in our paper.

Three series: Djougou, Medicina and Membach. Chronological 70/20/10 split.
Input 96 h, label context 48 h, forecast 24 h; stride 1 within each split.
StandardScaler uses training rows only. Adam, lr=0.001, batch=32,
max epochs=100, patience=10, MSE, best validation checkpoint; seeds 1001..1005.
PBI-Net: d_model=128, two interaction layers, Gaussian bandwidth=1 FFT bin,
periods 12/24 h, centers8/4, no future output mask.

Controls: no_cfi, period12, period24, shift_high(9/5), shift_low(7/3),
matched_mlp(hidden261), neutral_split(mask0.5), far_mask(16/12).
The complete argument lists are generated by tools/run_experiments.py --dry-run.

Harmonic1224 fits each input window independently, trend t/95, fixed ridge 1e-6,
intercept unpenalized, 12/24 h sine-cosine; future t=96..119.
Eight-constituent regression fits training coefficients only, with intercept,
training-standardized trend and M2/S2/N2/K2/K1/O1/P1/Q1 sine-cosine pairs.
Intercept and trend unpenalized; alpha grid0,1e-8,1e-6,1e-4,1e-2,1,100,
selected by validation-window MSE. Future phases/trend are extrapolated.

Report scaled-space MSE/MAE averaged over window-horizon pairs. Neural mean
and sample SD use five seeds(ddof=1); deterministic methods are single values.
Shared circular block bootstrap: paired windows and five seeds; blocks 12/24/36,
10000 replicates. Use analysis/shared_block_bootstrap.py with a results manifest.
